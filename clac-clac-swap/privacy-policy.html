Politique de confidentialité

Giga Bang (anciennement Clac Clac Swap)

Dernière mise à jour : 22 mars 2026

ProueStudio (ci-après "nous") développe et publie l'application mobile Giga Bang (ci-après "le Jeu"), disponible sur Google Play et l'App Store. Cette politique de confidentialité décrit comment nous collectons, utilisons et protégeons les informations lorsque vous utilisez notre Jeu.

1. Consentement

Lors de votre première utilisation, le Jeu vous demande votre consentement avant d'activer les publicités personnalisées et la collecte de données analytiques. Vous pouvez modifier ce choix à tout moment dans les Réglages du Jeu (option « Pubs personnalisées »).

Si vous refusez :

  • Vous verrez des publicités non personnalisées
  • Aucune donnée analytique ne sera envoyée à Firebase Analytics
  • Toutes les fonctionnalités du Jeu (classements, ligues, groupes d'amis) restent disponibles

Sur iOS (14.5+), le Jeu affiche également la demande de transparence du suivi (App Tracking Transparency) d'Apple.

2. Données collectées

Nous ne collectons aucune donnée personnelle directement (pas de nom réel, email, adresse, ni identifiant personnel).

Le Jeu utilise une authentification anonyme via Firebase Auth : un identifiant technique unique est créé automatiquement, sans que vous n'ayez à fournir d'informations personnelles. Cet identifiant permet de sauvegarder votre progression dans les classements.

Si vous choisissez un pseudo pour les classements, celui-ci est stocké sur nos serveurs mais ne constitue pas une donnée personnelle identifiable.

Les services tiers intégrés au Jeu peuvent collecter automatiquement certaines données techniques (uniquement si vous avez donné votre consentement pour les données analytiques) :

  • Identifiant publicitaire de l'appareil (GAID sur Android / IDFA sur iOS)
  • Modèle de l'appareil, version du système d'exploitation
  • Données d'utilisation anonymisées (sessions, événements dans le jeu)
  • Adresse IP (utilisée pour la localisation approximative par les services publicitaires)

3. Services tiers

Le Jeu utilise les services tiers suivants, chacun ayant sa propre politique de confidentialité :

Unity Ads (publicités)

Unity Ads affiche des publicités dans le Jeu. Avec votre consentement, il peut collecter des données pour personnaliser les annonces. Sans consentement, seules des publicités non personnalisées sont affichées.

Politique de confidentialité : https://unity.com/legal/privacy-policy

Firebase Analytics (analyse d'utilisation)

Firebase Analytics collecte des données anonymisées sur l'utilisation du Jeu (niveaux joués, scores, événements de jeu) afin de nous aider à améliorer l'expérience. Cette collecte est activée uniquement avec votre consentement et peut être désactivée à tout moment dans les Réglages.

Politique de confidentialité : https://firebase.google.com/support/privacy

Firebase Auth (authentification)

Firebase Auth fournit une authentification anonyme permettant d'identifier votre appareil pour les classements et les ligues. Aucune information personnelle n'est requise.

Cloud Firestore (base de données)

Cloud Firestore stocke les données liées aux classements, ligues et groupes d'amis : pseudo choisi, scores, progression dans les ligues. Ces données sont associées à votre identifiant anonyme.

Firebase Crashlytics (rapports de crash)

Crashlytics collecte automatiquement des informations techniques en cas de plantage du Jeu (pile d'appels, modèle d'appareil, version de l'OS) afin de nous permettre de corriger les bugs. Aucune donnée personnelle n'est incluse dans ces rapports.

4. Notifications locales

Le Jeu peut envoyer des notifications locales pour :

  • Rappeler la fin d'une saison de ligue
  • Annoncer le début d'une nouvelle saison
  • Encourager à revenir jouer après une période d'inactivité

Ces notifications sont générées entièrement sur votre appareil et aucune donnée n'est transmise à nos serveurs ni à des tiers. Vous pouvez les désactiver à tout moment dans les Réglages du Jeu ou dans les paramètres de votre appareil.

5. Stockage local

Le Jeu sauvegarde votre progression (scores, niveaux débloqués, paramètres, choix de consentement) localement sur votre appareil via le stockage de l'application.

6. Public visé

Le Jeu est destiné à un public de 13 ans et plus. Nous ne collectons pas sciemment de données auprès d'enfants de moins de 13 ans.

7. Partage des données

Nous ne vendons, n'échangeons ni ne transférons vos données personnelles à des tiers, en dehors des services tiers mentionnés ci-dessus qui sont nécessaires au fonctionnement du Jeu.

8. Sécurité

Nous prenons des mesures raisonnables pour protéger les informations traitées par le Jeu. Cependant, aucune méthode de transmission ou de stockage électronique n'est totalement sécurisée.

9. Vos droits (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

  • Droit d'accès : demander quelles données sont collectées
  • Droit de suppression : demander la suppression de vos données
  • Droit d'opposition : refuser le traitement de vos données à des fins publicitaires
  • Gestion du consentement : vous pouvez modifier votre choix de consentement à tout moment dans les Réglages du Jeu (option « Pubs personnalisées »)
  • Désactivation du suivi iOS : Réglages > Confidentialité et sécurité > Suivi
  • Désactivation du suivi Android : Paramètres > Google > Annonces

10. Modifications

Nous nous réservons le droit de mettre à jour cette politique de confidentialité. Toute modification sera publiée sur cette page avec une date de mise à jour révisée.
