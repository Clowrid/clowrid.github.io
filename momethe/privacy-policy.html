Politique de confidentialité

MoMethe — Mots Mêlés Thématiques

Dernière mise à jour : 25 mai 2026

ProueStudio (ci-après "nous") développe et publie l'application mobile MoMethe — Mots Mêlés Thématiques (ci-après "le Jeu"), disponible sur Google Play et l'App Store. Cette politique de confidentialité décrit comment nous collectons, utilisons et protégeons les informations lorsque vous utilisez notre Jeu.

1. Données collectées

Nous ne collectons aucune donnée personnelle directement (pas de nom réel, email, adresse, ni identifiant personnel).

Le Jeu utilise une authentification anonyme via Firebase Auth : un identifiant technique unique est créé automatiquement, sans que vous n'ayez à fournir d'informations personnelles. Cet identifiant permet de sauvegarder votre progression dans les classements.

Si vous choisissez un pseudo pour les classements, celui-ci est stocké sur nos serveurs mais ne constitue pas une donnée personnelle identifiable.

Les services tiers intégrés au Jeu peuvent collecter automatiquement certaines données techniques :

  • Identifiant publicitaire de l'appareil (GAID sur Android / IDFA sur iOS)
  • Modèle de l'appareil, version du système d'exploitation
  • Adresse IP (utilisée pour la localisation approximative par les services publicitaires)
  • Jeton de notification push (FCM token) : identifiant technique unique de l'appareil utilisé pour envoyer les notifications de duel (invitation reçue, tour à jouer). Ce jeton est lié uniquement à votre identifiant Firebase anonyme, jamais à votre identité.
  • Données de diagnostic : rapports de plantage anonymisés pour améliorer la stabilité du Jeu

2. Services tiers

Le Jeu utilise les services tiers suivants, chacun ayant sa propre politique de confidentialité :

Publicités — médiation Unity LevelPlay (Unity Ads & Google AdMob)

Les publicités du Jeu se limitent à des vidéos récompensées facultatives (regardées volontairement en échange d'un bonus). Elles sont diffusées via la plateforme de médiation Unity LevelPlay, qui met en concurrence plusieurs régies publicitaires — principalement Unity Ads et Google AdMob — pour afficher l'annonce la plus pertinente. Ces régies peuvent collecter des données techniques (identifiant publicitaire, adresse IP, type d'appareil) afin de diffuser et mesurer les annonces. Vous pouvez supprimer définitivement les publicités via un achat intégré.

Politiques de confidentialité des régies :

  • Unity Ads / LevelPlay : https://unity.com/legal/privacy-policy
  • Google AdMob : https://policies.google.com/privacy (voir aussi comment Google utilise les données)

Consentement publicitaire (EEE, Royaume-Uni, Suisse) : si vous résidez dans ces régions, un formulaire de consentement certifié par Google (User Messaging Platform) vous est présenté afin de recueillir votre choix concernant les publicités personnalisées. En l'absence de consentement, seules des publicités non personnalisées peuvent être diffusées. Vous pouvez retirer ou modifier ce consentement à tout moment (voir §7 et les réglages publicitaires de votre appareil).

Firebase Auth (authentification)

Firebase Auth fournit une authentification anonyme permettant d'identifier votre appareil pour les classements. Aucune information personnelle n'est requise.

Politique de confidentialité : https://firebase.google.com/support/privacy

Cloud Firestore (base de données)

Cloud Firestore stocke les données liées aux classements et aux duels multijoueurs : pseudo choisi, scores, codes d'invitation de duel (6 caractères), liste des participants à un duel et résultats de chaque partie. Ces données sont associées à votre identifiant Firebase anonyme.

Firebase Cloud Messaging (notifications push)

Firebase Cloud Messaging (FCM) envoie les notifications push transactionnelles liées aux duels multijoueurs : invitation reçue d'un ami, tour à jouer dans un duel en cours. Aucune notification marketing n'est envoyée. Le jeton FCM est stocké sur nos serveurs uniquement pour cibler votre appareil et peut être supprimé à tout moment en désactivant les notifications dans les réglages système ou dans l'écran Réglages du Jeu.

Politique de confidentialité : https://firebase.google.com/support/privacy

Firebase Crashlytics (rapports de plantage)

Firebase Crashlytics collecte automatiquement des rapports de plantage anonymisés (pile d'appels, version de l'appli, modèle d'appareil) afin d'identifier et corriger les bugs. Aucune donnée personnelle n'est transmise.

Firebase Analytics (statistiques d'usage)

Firebase Analytics collecte des statistiques agrégées et anonymes sur l'utilisation du Jeu (écrans consultés, niveaux joués, fonctionnalités utilisées) pour améliorer l'expérience utilisateur.

RevenueCat (achats intégrés)

RevenueCat gère les achats intégrés dans le Jeu (suppression des publicités). Les transactions sont traitées par Apple (App Store) ou Google (Google Play) selon votre appareil. RevenueCat ne collecte aucune donnée financière directement — seul un identifiant anonyme est utilisé pour vérifier le statut de votre achat.

Politique de confidentialité : https://www.revenuecat.com/privacy

3. Stockage local

Le Jeu sauvegarde votre progression (scores, niveaux débloqués, paramètres) localement sur votre appareil via le stockage de l'application.

4. Public visé

Le Jeu est destiné à un public de 13 ans et plus. Nous ne collectons pas sciemment de données auprès d'enfants de moins de 13 ans.

5. Partage des données

Nous ne vendons, n'échangeons ni ne transférons vos données personnelles à des tiers, en dehors des services tiers mentionnés ci-dessus qui sont nécessaires au fonctionnement du Jeu.

6. Sécurité

Nous prenons des mesures raisonnables pour protéger les informations traitées par le Jeu. Cependant, aucune méthode de transmission ou de stockage électronique n'est totalement sécurisée.

7. Vos droits (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

  • Droit d'accès : demander quelles données sont collectées
  • Droit de suppression : demander la suppression de vos données
  • Droit d'opposition : refuser le traitement de vos données à des fins publicitaires
  • Désactivation du suivi iOS : Réglages > Confidentialité et sécurité > Suivi
  • Désactivation du suivi Android : Paramètres > Google > Annonces
  • Désactivation des notifications push : dans l'écran Réglages du Jeu, ou dans les réglages système de votre appareil (iOS : Réglages > Notifications > MoMethe ; Android : Paramètres > Applications > MoMethe > Notifications)

8. Modifications

Nous nous réservons le droit de mettre à jour cette politique de confidentialité. Toute modification sera publiée sur cette page avec une date de mise à jour révisée.
